# Cobbly

A cozy block puzzle. No timer, no pressure: when you get stuck, the level
settles back on its own. A new board every day, the same for everyone.

**Play: https://cobbly.app**

This repository holds only the built page. It is written by `npm run pubblica`
from the source repository, and hand edits here are overwritten by the next
publish — except `README.md`, `CNAME` and `.nojekyll`, which live only here and
are excluded from the sync.
